# 📝 Changelog

All notable changes to Gym Tracker will be documented here.

## [1.0.0] - 2026-08-15

### ✨ Features
- ✅ Hiển thị lịch tập 7 ngày trong tuần
- ✅ Đánh dấu hoàn thành bài tập và ngày tập
- ✅ Ghi nhận kết quả (trọng lượng, số lần)
- ✅ Ghi chú cá nhân cho từng bài tập
- ✅ Xem lịch sử tập của từng bài
- ✅ Điều hướng qua các tuần
- ✅ Theo dõi streak (số ngày tập liên tiếp)
- ✅ Export/Import dữ liệu
- ✅ Xóa toàn bộ dữ liệu
- ✅ PWA support (cài như app native)
- ✅ Offline mode (Service Worker)
- ✅ Responsive design (mobile + desktop)
- ✅ Dark theme mặc định

### 📚 Documentation
- ✅ README với hướng dẫn cơ bản
- ✅ HUONG-DAN.md - Hướng dẫn chi tiết tiếng Việt
- ✅ DEPLOY.md - Hướng dẫn deploy lên GitHub Pages & Cloudflare
- ✅ QUICKSTART.md - Bắt đầu nhanh trong 5 phút
- ✅ ICON-INFO.md - Hướng dẫn tạo icon

### 🛠️ Technical
- HTML5, CSS3, Vanilla JavaScript
- LocalStorage để lưu dữ liệu
- Service Worker cho offline
- GitHub Actions cho CI/CD
- Cloudflare Pages compatible
